# OneHelp

OneHelp is a responsive Progressive Web Application that connects volunteers
with verified social, health, environmental and emergency-response actions.

## Project status

Early MVP development.

## Main applications

- `frontend/` – Vue 3 volunteer and organizer web application
- `backend/` – Spring Boot REST API
- `docs/` – Product and technical documentation
- `deployment/` – Docker and infrastructure configuration

## Planned technology stack

### Frontend

- Vue 3
- TypeScript
- Vuetify 3
- Vue Router
- Pinia
- Vite
- PWA

### Backend

- Spring Boot
- Spring Security
- PostgreSQL
- JWT authentication
- Flyway

### Infrastructure

- Docker
- Docker Compose
- Nginx
- GitHub Actions

## Core MVP features

- Volunteer registration and profile
- Action discovery
- Map and filters
- Participation registration
- Organizer dashboard
- QR check-in
- Attendance history
- Administration and organization verification
